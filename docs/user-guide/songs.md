# Prepare a song

In **Libraries → Songs**, choose New song, or **Quick Song** to paste a title, lyrics, and tags. Blank lines in Quick Song create separate sections.

Edit sections as cards, then arrange them with Song order. Repeat a section when it should appear again. Tags help you find songs by theme or occasion.

For two languages, choose a second language and enter matching translation rows in each section. Use a bilingual lyrics template so both languages remain visible.

Save the song, choose a layout and lines per slide, then Add to program. Select the destination with the arrow beside that button.
