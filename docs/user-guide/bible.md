# Display scripture

In **Libraries → Bible**, select a translation and book. The book opens at chapter 1. Use the chapter grid to change chapters, and the verse grid to scroll to and highlight a verse. Click verse cards to select several, or Select chapter.

## Two Bibles on the same slide

Choose **Second Bible (optional)**. Selah matches each reference by book, chapter, and verse, including when the book names use different languages. Both texts appear in the reading list.

Choose **Automatic layout** or **Dual Bible**, then Add to program. If the second Bible lacks a selected verse, choose another Bible or remove that verse. Selah will not silently substitute another reference.

Long verses continue across slides. A shorter translation stays visible while the longer translation continues. Translation wording and verse numbering can differ; review the output before presenting.

## Add a translation

Choose Import translation to browse the GitHub catalog or import a local XML/JSON file. Download progress appears during import. Once imported, the Bible is available offline.

## Verse splitting

Each verse keeps its reference when it spans multiple slides. Automatic layouts
and templates share the same shaped-text fitting and pagination. Complete
paragraphs and sentences are preferred, then clauses and supported conjunctions.
The verse text, punctuation and order are preserved exactly. Paired Bibles retain
the same reference and repeat the shorter translation while the longer continues.

Shrink-to-fit boxes first try to keep the full verse together down to their minimum
font size. If a complete phrase still cannot fit, Selah reports the box/line-limit
problem rather than cutting at an arbitrary word. Increase the box, allow more
lines, or lower the minimum size. Prepared program snapshots stay unchanged until
you apply the layout and deliberately present the updated content.

Use **↑ / ←** and **↓ / →** after selecting a verse card or verse number to browse adjacent verses. The selection scrolls into view; search results stay within the result list, while chapter browsing can continue into the next chapter. Arrow keys keep their normal text-editing and dropdown behavior when those controls have focus. Browsing does not take a verse live.

Book matching is shared with Luma. For example, `adikandam 1:1`,
`ఆదికాండము ౧:౧`, `utpatti 1:1`, and `Genesis 1:1` can resolve the same book and
verse in your selected translation. English, Telugu and Hindi book catalogs are
built in; localized book names from imported Bibles extend the index. Other
language coverage depends on those names being present. The matcher normalizes
Romanized spelling variations and asks you to choose when candidates tie.

After selecting the result of a reference search, arrow navigation can continue
to adjacent verses outside the searched range. Ordinary word searches still
navigate only their matching results. Searching and browsing never take a verse
live automatically.
