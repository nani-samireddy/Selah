# Display scripture

In **Libraries → Bible**, select a translation and book. The book opens at chapter 1. Use the chapter grid to change chapters, and the verse grid to scroll to and highlight a verse. Click verse cards to select several, or Select chapter.

## Two Bibles on the same slide

Choose **Second Bible (optional)**. Selah matches each reference by book, chapter, and verse, including when the book names use different languages. Both texts appear in the reading list.

Choose **Automatic layout** or **Dual Bible**, then Add to program. If the second Bible lacks a selected verse, choose another Bible or remove that verse. Selah will not silently substitute another reference.

Long verses continue across slides. A shorter translation stays visible while the longer translation continues. Translation wording and verse numbering can differ; review the output before presenting.

## Add a translation

Choose Import translation to browse the GitHub catalog or import a local XML/JSON file. Download progress appears during import. Once imported, the Bible is available offline.
