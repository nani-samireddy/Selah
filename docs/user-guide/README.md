# Selah user guides

Open the book icon or **Help → User guide** to search these guides offline.
Choose **Start walkthrough** for step-by-step coaching inside the app. Each step
opens the relevant workspace and outlines its control. Try the controls, use
Previous/Next, or end the walkthrough at any time. Finished walkthroughs are
remembered on this computer and can be replayed.

Walkthrough navigation does not create content, load a program or enable output.
Any changes you choose to make while following a walkthrough are real edits.
Closing a walkthrough leaves you in your current workspace.

The in-app reader loads these same Markdown files, so written and in-app guides
stay synchronized.
