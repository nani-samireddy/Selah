# Design your content

**Templates** define reusable layouts for songs and scripture. **Presentations** contain their own editable content and can have multiple slides. A template is one reusable canvas. Open either from Libraries to edit it in Design.

For dual Bibles, start from the **Dual Bible** template. In the text inspector, bind the first text box to Scripture text and the second to **Secondary scripture text**. Use Secondary scripture reference, Secondary version, and Secondary credits for the second Bible’s metadata.

Select an element and drag any of its four corner markers to resize it. Handles
remain usable while editing text or when other layers overlap. Resizing keeps the
opposite corner fixed, supports rotated layers, and can be undone in one step.
Locked layers show an outline without active handles; unlock them in Layers first.

Pinch on the canvas to zoom around the gesture position. Two-finger scrolling pans the
canvas; Ctrl/Cmd + scrolling zooms around the pointer. A mouse wheel also zooms.
Drag with the Hand tool or hold the middle mouse button to pan over any element.
Click the zoom percentage in the floating toolbar to reset the view to Fit.
Floating panels keep their own scrolling and do not zoom the canvas behind them.

Each text box has independent font, size, color, alignment, and position. Keep bound boxes inside the canvas. If text cannot fit, enlarge the box or reduce the font size.

Save a template and select it when adding library content to a program. Existing program snapshots keep their previous layout until you explicitly apply a new layout.

Find layouts using the searchable preview cards in Libraries → Templates. Click anywhere on a
card to open its editor directly. When choosing a template from a program item,
a card opens the content preview before you apply the layout.
When choosing a font, the picker previews selected words, or the whole text layer
if there is no text selection. Selecting an online family loads its real typeface automatically for preview. This
requires an internet connection the first time; Download & use keeps the complete
family available offline. Browsing previews does not apply the font.

To change a template or slide background, select **Background** beneath Layers (or
click an empty canvas area), then use **Properties → Canvas background**. Choose
**Solid color** to edit the fill/hex value or open the color picker, or **Transparent** to
remove the canvas fill. **Linear gradient** and **Radial gradient** offer 2–8 color
stops with editable positions and stop colors/alpha; linear gradients also have an
angle. **Image** imports a background into local storage. Use Fill to crop, Fit to
show the entire image over the chosen canvas color, or Stretch to fill without
preserving its aspect ratio. **Fill opacity** affects the background only. Text, images and graphics keep their own visibility and
opacity. **Ambient pattern** is optional; new templates start without it.

The checkerboard shows transparent areas in the editor and library previews only.
It is not sent to displays or NDI. Returning to Color restores the previous fill.
Save/update the template to keep the setting; prepared program snapshots change
only when you explicitly reapply the updated template.

## Undo, redo and compact slides

Undo and Redo are in the top editor toolbar. Use Cmd+Z / Shift+Cmd+Z on macOS,
or Ctrl+Z / Ctrl+Y on Windows. Select a canvas object or empty canvas to return
keyboard focus from a property field to the canvas. Text fields keep their own
editing history while focused.

The Slides button in the floating toolbar minimizes the large slide and notes
panel into a short thumbnail strip beside the toolbar. Click a compact thumbnail
to switch slides. Expand it again to add slides or edit speaker notes.
