# Design your content

**Templates** define reusable layouts for songs and scripture. **Custom slides** are presentations with their own editable content. Open either from Libraries to edit it in Design.

For dual Bibles, start from the **Dual Bible** template. In the text inspector, bind the first text box to Scripture text and the second to **Secondary scripture text**. Use Secondary scripture reference, Secondary version, and Secondary credits for the second Bible’s metadata.

Each text box has independent font, size, color, alignment, and position. Keep bound boxes inside the canvas. If text cannot fit, enlarge the box or reduce the font size.

Save a template and select it when adding library content to a program. Existing program snapshots keep their previous layout until you explicitly apply a new layout.
