# Welcome to Selah

Prepare your content in **Libraries**, arrange a service in **Programs**, customize layouts in **Design**, and operate it in **Present**.

1. Open Programs, then open a program card or choose New program.
2. Open Libraries and choose Songs, Bible, Media, or Presentations.
3. Use **Add to program** to add your content. Its arrow lets you choose a different destination.
4. In the program editor, drag items into service order.
5. Open Outputs and select your audience and speaker displays.
6. Open Present, choose a program in the selector, then Load program. Review its slides before enabling audience output. When output is active the action says Take program live.

Check the audience display before the service. Editing a library item does not automatically change an already prepared program snapshot.

## Follow an interactive walkthrough

Open the book icon, choose **Your first service**, and select **Start walkthrough**.
A small coaching card opens the relevant workspaces and outlines each control.
You can try controls, move back and forth, read the full guide or end the tour.
The tour does not create content or turn on outputs. Work you choose to save while
following it remains in your library. Finished walkthroughs can be replayed.
