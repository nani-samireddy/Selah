# Selah identity

The SVGs preserve the user-supplied mark. Its ink is inverted from `#1d1c1a` to `#e2e3e5` for the dark theme. The toolbar variant centers the view box; `app-icon.svg` places the same light mark on a dark tile. PNG, ICNS, and ICO derivatives are rendered from that vector. This user-supplied mark is separate from Lucide interface icons and their license.
