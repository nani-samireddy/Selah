
`bible-repository.json` contains filename/language/size metadata from
`nani-samireddy/Holy-Bible-XML-Format` (`master`), with the source Git-tree commit recorded. It includes
the full tree rather than the first 1,000 directory entries. Refresh it with
`python3 scripts/build-bible-catalog.py`. Bible texts from that repository are downloaded by the
operator on demand and are not included in the app's seed database or resources.
