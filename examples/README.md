# Import examples

`songs/` contains `churchdeck-song-1` JSON files that can be imported through Libraries → Songs. The `sample-*` songs contain original demonstration lyrics, including Telugu/Hindi/bilingual content, alternate arrangements, long lines and forced slide breaks.

`na-thalliyu-neeve.json` contains the Telugu song supplied by the user. No author or license has been inferred for it. It preserves repeat markings and includes an as-supplied arrangement plus a chorus-between-verses alternative.

Examples are import data, not automatically installed runtime content. Importing creates a new song identity. See the [content guide](../docs/features/content-libraries.md) for the format.

`templates/basic-lyrics.churchtemplate` is a minimal importable lyrics layout with a bound primary text box. See the [template guide](../docs/features/templates.md).
